SWRP Genesis Map is an interactive galaxy map made for the SWRP Genesis roleplay forum using the Leaflet framework. It's an ambitious project that, upon completion, will see every named Star Wars planet and moon mapped for use by the SWRP community in its Faction War PVP system.

In addition to mapped planets and moons, the SWRP Genesis map features a robust search function, faction territory overlays, and hyperlanes.

The map also includes Star Wars Battlefront II easter eggs - the Galactic Conquest game mode theme and planet select SFX, integrated through toggleable buttons beside the search bar.
